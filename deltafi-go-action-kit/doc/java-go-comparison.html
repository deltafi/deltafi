DeltaFi Action Kit: Java vs Go Comparative Analysis

Based on deltafi-java-hello-world and deltafi-go-hello-world reference plugins

Overview: Both action kits provide the same capabilities — transform, split, join, egress, and timed ingress actions with support for content manipulation, metadata, annotations, lookup tables, and artifact management. The Java kit uses Spring Boot with annotation-based registration and class inheritance. The Go kit uses typed generic registration functions with a Deltafile-centric API.

1. Plugin Bootstrap

Java

@SpringBootApplication
public class HelloWorld {
    public static void main(String[] args) {
        SpringApplication.run(HelloWorld.class, args);
    }
}

Go

// plugin.yaml provides groupId, artifactId, domain, description.
// The Makefile extracts those fields and stamps them into the binary
// via -ldflags at docker build time.
func main() {
    actionkit.RunPlugin()
}
Key difference: Java uses Spring Boot auto-configuration and classpath scanning. Go plugins keep main trivial: a single RunPlugin() call. Plugin identity lives in plugin.yaml at the source root; the Makefile reads it at build time and stamps the values into kit-exported globals via -ldflags -X. Actions self-register via init() functions in Go, vs @Component annotation in Java.

2. Action Registration

Java

@Component
public class HelloWorldJavaTransformAction
    extends TransformAction<HelloWorldJavaTransformParameters> {

    public HelloWorldJavaTransformAction(...) {
        super("Add some content noting that we did a really good job");
    }
}

Go

//go:embed transform_action.yaml
var transformActionOptions string

func init() {
    actionkit.RegisterTransform(
        "HelloWorldGoTransformAction",
        &HelloWorldGoTransformAction{}).
        WithParams(HelloWorldGoTransformParams{}).
        WithOptionsYAML(transformActionOptions)
}
Key difference: Java uses class inheritance (extends TransformAction<P>) to declare the action type and bind the params type. Go uses typed generic registration functions (RegisterTransform, RegisterEgress, RegisterIngress, RegisterJoinTransform) — the compiler enforces the method signature via interface constraints and infers the params type. Action options are declared in an embedded YAML file in Go.

Go

type HelloWorldGoTransformParams struct {

Key difference: Java uses Lombok @Data for getters/setters and Jackson annotations for schema metadata. Go uses struct tags (description, default) — no code generation or annotation processing needed.

4. Transform Action

Java

@Override
public TransformResultType transform(
    @NotNull ActionContext context,
    @NotNull HelloWorldJavaTransformParameters params,
    @NotNull TransformInput input) {

  // Filter
  if (context.getDid().toString()
      .startsWith(params.getDidFilterPrefix())) {
    return new FilterResult(context,
        "Filter due to did_filter_prefix match");
  }

  // Error
  if (context.getDid().toString()
      .startsWith(params.getDidErrorPrefix())) {
    return new ErrorResult(context,
        "Error due to did_error_prefix match",
        params.getDidErrorPrefix() + " detected");
  }

  // Load content
  String data = input.getContent().getFirst()
      .loadString();

  // Save new content
  TransformResult result = new TransformResult(context);
  ActionContent content = result.saveContent(
      data.getBytes(), "name", MediaType.TEXT_PLAIN);
  content.addTag("hello-file");

  // Metadata & annotations
  result.addMetadata("key", "value");
  result.addAnnotation("language", "English");

  return result;
}

Go

func (a *HelloWorldGoTransformAction) Transform(
    df *actionkit.Deltafile,
    params HelloWorldGoTransformParams,
) *actionkit.Deltafile {

  // Filter
  if strings.HasPrefix(df.Did,
      params.DidFilterPrefix) {
    return df.Filterf(
        "Filter due to did_filter_prefix match")
  }

  // Error
  if strings.HasPrefix(df.Did,
      params.DidErrorPrefix) {
    return df.Errorf(
        "Error due to did_error_prefix match").
        SetErrorContext(
            params.DidErrorPrefix + " detected")
  }

  // Load content
  content, _ := df.ContentAt(0)
  data, _ := content.LoadString()

  // Save new content
  newContent, _ := df.SaveStringContent(
      data, "name", "text/plain")
  newContent.AddTag("hello-file")

  // Metadata & annotations
  return df.
      AddMetadata("key", "value").
      AddAnnotation("language", "English")
}
Key differences:
• Java: Separate result types (TransformResult, ErrorResult, FilterResult) returned via a TransformResultType union. ActionContext passed explicitly.
• Go: The Deltafile IS the result — error/filter state is set on it via Errorf()/Filterf(). All methods are chainable. No separate context object; context fields live on the Deltafile (df.Did, df.Name, etc.). Params are typed and passed directly.

5. Split / Multi-Child Transform

Java

@Override
public TransformResultType transform(
    @NotNull ActionContext context,
    @NotNull Params params,
    @NotNull TransformInput input) {

  TransformResults manyResults =
      new TransformResults(context);

  String data = input.getContent()
      .getFirst().loadString();
  ActionContent content =
      ActionContent.saveContent(context,
          data.getBytes(), "content", "text/plain");

  for (int n = 0; n < params.getNumberOfChildren(); n++) {
    String name = context.getDeltaFileName() + "-" + n;
    ChildTransformResult child =
        new ChildTransformResult(context, name);
    child.addContent(content);
    child.addMetadata("key", "value");
    child.addAnnotation("childIndex", "" + n);
    manyResults.add(child);
  }

  return manyResults;
}

Go

func (a *HelloWorldGoSplitTransformAction) Transform(
    df *actionkit.Deltafile,
    params HelloWorldGoSplitTransformParams,
) *actionkit.Deltafile {

  content, err := df.ContentAt(0)
  if err != nil {
    return df.Errorf("No content")
  }
  data, _ := content.LoadString()

  for n := range params.NumberOfChildren {
    name := fmt.Sprintf("%s-%d", df.Name, n)
    child := df.AddChild(name)
    child.SaveStringContent(
        data, "content", "text/plain")
    child.AddMetadata("key", "value").
        AddAnnotation("childIndex", strconv.Itoa(n))
  }

  return df
}
Key difference: Both kits use the same Transform method for splits. Java returns a TransformResults container. Go calls df.AddChild(name) to create children — the kit detects children and produces a multi-child transform event automatically. An action can decide at runtime whether to split or not based on the input.

7. Egress Action

Java

@Override
public EgressResultType egress(
    @NotNull ActionContext context,
    @NotNull ActionParameters params,
    @NotNull EgressInput input) {

  String data = new String(
      input.getContent().loadBytes(),
      StandardCharsets.UTF_8);

  if (data.contains("error")) {
    return new ErrorResult(context,
        "Failed to egress",
        new Exception("error in content"));
  }

  return new EgressResult(context);
}

Go

func (a *HelloWorldGoEgressAction) Egress(
    df *actionkit.EgressDeltafile,
    params struct{},
) *actionkit.EgressDeltafile {

  content, _ := df.FirstContent()
  data, _ := content.LoadString()

  if strings.Contains(data, "error") {
    return df.Errorf("Failed to egress").
        SetErrorContext("error in content")
  }

  return df
}

Egress restriction: Egress actions receive an *EgressDeltafile — a constrained view of the Deltafile that exposes content/metadata reads, logging, annotations, and error/filter signaling, but not output-content or metadata mutations. The EGRESS event format does not carry those, so the protection is enforced at compile time rather than as a silent drop.

8. Timed Ingress Action

Java

@Override
public IngressResultType ingress(
    @NotNull ActionContext context,
    @NotNull ActionParameters params) {

  int index = 0;
  if (context.getMemo() != null) {
    index = 1 + Integer.parseInt(
        context.getMemo());
  }

  String filename = context.getFlowName()
      + "-" + index;
  IngressResultItem item =
      new IngressResultItem(context, filename);
  item.saveContent("Content " + index,
      filename, "text/plain");
  item.addMetadata("index",
      String.valueOf(index));

  IngressResult result =
      new IngressResult(context);
  result.addItem(item);
  result.setMemo(String.valueOf(index));
  return result;
}

Go

func (a *HelloWorldGoTimedIngressAction) Ingress(
    deltafile *actionkit.TimedIngressDeltafile,
    params struct{},
) *actionkit.TimedIngressDeltafile {

  index := 0
  if deltafile.Memo != "" {
    if parsed, err := strconv.Atoi(
        deltafile.Memo); err == nil {
      index = parsed + 1
    }
  }

  filename := fmt.Sprintf("%s-%d",
      deltafile.FlowName, index)
  item := deltafile.NewItem(filename)
  item.SaveStringContent(
      fmt.Sprintf("Content %d", index),
      filename, "text/plain")
  item.AddMetadata("index",
      strconv.Itoa(index))

  return deltafile.SetMemo(strconv.Itoa(index))
}

Timed ingress restriction: The action receives a single *TimedIngressDeltafile that replaces the previous IngressInput/IngressResult pair. NewItem(name) returns an *IngressDeltafile — a write-only Deltafile view that exposes only the content/metadata/annotation writes that the ingress wire event carries. Reads, child creation, and per-item error/log are intentionally excluded.

9. Lookup Table Queries

Java

// Injected via constructor
private final LookupTableClient lookupTableClient;

LookupResults colors = lookupTableClient.lookup(
    "java_scheduled_lookup_table",
    LookupOptions.builder()
        .matchingColumnValues(
            Map.of("color", Set.of("red", "green")))
        .resultColumns(Set.of("column_a"))
        .build());

for (Map<String, String> row : colors.results()) {
    String value = row.get("column_a");
}

Go

// Package-level function, no injection needed
results, err := actionkit.Lookup(
    "go_scheduled_lookup_table",
    actionkit.LookupQuery().
        WithMatch("color", "red", "green").
        WithResultColumns("column_a"))

for _, row := range results.Rows {
    value := row["column_a"]
}

// ConfigureArtifacts method (detected via interface)
