## [2.53.0] - 2026-04-17

### Added
- Quick Start Checklist
- Added a new parameter `invalidFormatMode` to the ExtractJson and ExtractXml actions to allow invalid content format to error (default), drop, or passthrough
- Added a new parameter `allowScalarRoot` to the ExtractJson action which defaults to TRUE. Can be set to FALSE to require JSON root to be an object or array
- Go and Python plugins can now opt out of Dockerfile updates during `deltafi plugin generate update` by setting `ARG CUSTOM_DOCKERFILE=true`
- Plugin updates now preserve user-added and user-modified ENV variables in Dockerfiles
- Go action kit supports YAML format for flow variable files (`variables.yaml`), with multi-document support
- Go action kit pre-production candidate
- Go plugin generation fully supported from TUI
- Lookup table setup documentation

### Changed
- Kubernetes install instructions reference TUI install 
- Hovering over the Hamburger button no longer pops open the left side navigation menu 
- Go plugin code generator now produces `variables.yaml` instead of `variables.json` for flow variables
- Documentation updated to correctly reference go plugin actions
- Normalized `delta_files.data_source` from a text column to an integer foreign key referencing `flow_definitions`, significantly reducing index sizes
- Allow override of s3-proxy persistantVolume mount with hostPath
- Updated the main navigation to a stable top-bar layout with section dropdowns, rolled-up status badges, and a compact menu fallback on narrower screens.

### Fixed
- Refresh on the Data Sources Page no longer clears out any work done while setting a schedular
- Pause button is now highlighted when a flow is paused
- Set Cron Schedule dropdowns are now longer hidden requiring the user to scroll to see them
- Data Table Loading text color changed to make it easier to read
- Refresh on the DeltaFile viewer now loads new rows into the Flow Table
- Fixed panel headers and dataTable alternating rows to use a darker gray. The dataTable header row uses white instead of gray.
- Fix database lock contention between bulk acknowledge and auto-resume that caused queries to block for minutes
- Fixed the documentation for setting environment variables in plugins for action parameters
- Improve Errors and Filtered page load speed by only querying data for the visible tab and using a lightweight query for the cause filter dropdown
- Add covering indexes to improve Filtered and Error page performance
- Plugin updates no longer overwrite user-edited flow definition files (`variables.yaml`, `variables.json`, `data-source.json`)

### Upgrade and Migration
- Upgrade java JRE base image to deltafi/deltafi-java-jre:21.0.10-alpine-2
- Database migration V73 normalizes `delta_files.data_source` and rebuilds 5 indexes. On large tables (10M+ rows) this may take several minutes. Plan for downtime during this upgrade.
