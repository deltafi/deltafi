## [2.45.2] - 2025-12-31

### Added
- Added a `created` and `modified` field to the `lookup_tables` records and exposed them to the `lookup` query
- Added table name validation when creating lookup tables to prevent attempting create table with invalid names 
- Added table lookup validation step to reject `last_updated` in the column list to avoid conflicting with the autopopulated `last_updated` column
- TUI: `deltafi plugin install` `--wait` flag added

### Fixed
- Fixed issue where paused DeltaFiles in join entries could block unpausing of other DeltaFiles due to optimistic locking conflicts
- Fix spelling on property group name: Metrics and Analytics
- Fixed an issue where updating plugins could lead two a false error about duplicate lookup tables across plugins
- Fixed replay to queue files when flow is invalid or plugin is not ready (consistent with ingress behavior)
- Fixed publishing to queue files when the subscriber's plugin is not ready
- Fix bug where placeholder flow could get stuck 
- Show placeholder status as waiting for plugin on data source/transform/data sink pages
- `deltafi plugin uninstall` tab completes to installed plugin names
- [python-action-kit] The DeltaFile log message for an ErrorResult is now generated before messages are serialized
- Removed annoying "Powered by" popover on dashboard charts
- Fixed data source flows that were paused after ingress completed but before publishing to subscribers
- Fixed requeue mechanism to persist error state when action configuration is not found
- Fixed requeue query to exclude actions in JOINING state

### Tech-Debt/Refactor
- Refactored the lookup query to use parameters and sanitize identifiers (i.e. column names) throughout the query
- Optimize processing of unpaused DeltaFiles: reduce batch size and distribute action results across workers 
- Added partial index on paused DeltaFiles to improve unpause query performance

### Upgrade and Migration
- Upgrade dozzle to amir20/dozzle:v8.14.12
- Upgrade Java base image to deltafi/deltafi-java-jre:21.0.9-alpine-4
- Upgrade Python base image to deltafi/python:3.13.11-1
- Upgrade Grafana to deltafi/grafana:12.4.0-4
- Upgrade Valkey to deltafi/valkey:9.0.1-0
- Upgrade Promtail to grafana/promtail:3.6.3
- Upgrade Postgres to deltafi/postgres:16.11-0
