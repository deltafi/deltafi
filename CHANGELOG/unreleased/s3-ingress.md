# Changes on branch `s3-ingress`
Document any changes on this branch here.
### Added
- Added S3Ingress - a timed ingress action that polls an S3 bucket for objects to ingress
- Added S3GetObjectsFromEvent - an action that uses S3 event notifications to trigger getting content from an S3 store
- Added S3DeleteObject - an action that deletes an object from an S3 store
- Added S3CopyObject - an action that copies objects within an S3 store
- Added S3PutObjectTagging - an action that applies a tag to an object in an S3 store
- Added S3Egress - an egress action that writes content to an S3 store
