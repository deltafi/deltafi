## [2.56.0] - 2026-06-03

### Added
- Added a new mutation that redeploys an installed plugin (useful when plugin environment variables are updated and need to be pushed out)
   ```graphql
   mutation RedeployPlugin($groupId: String!, $artifactId: String!, $version: String!) {
     redeployPlugin(pluginCoordinates: { groupId: $groupId, artifactId: $artifactId, version: $version }) {
       success
         info
         errors
       }
   }
   ```
- Added a new command, `deltafi plugin redeploy`, that is used to redeploy a plugin 
- Added a `redeploy plugin` option in the GUI Plugins page in the plugin context menu
- Added new SPeL method support for action parameters including base64Encode, base64Decode and sha256 (see action parameters docs for full details)
- New `LineSplit` action splits each line of content into its own subcontent

### Changed
- Expanded S3 actions documentation

### Fixed
- Fixed issue where you cant set enumerated parameter back to null 
- Fixed drop-down expanding off the page if several chips or long chips were added to them
- Fixed top nav menu click issue
- Fixed an issue where flows that include JSON fields that have a special characters in the key could not be saved. For example, attempting to save a transform that used ModifyMetadata to rename a key from "SOME KEY" to "SOME_KEY" would previously fail.
- Fixed a requeue stall where the core scheduler's batch save of cold-to-warm, timed-requeue, rate-limited, and unpaused DeltaFiles would roll back in full whenever a single file in the batch was modified concurrently (common for forking DeltaFiles whose sibling flow is processed while another flow is requeued). The batch re-selected the same files and failed every cycle, making no progress. The scheduler now degrades to saving and dispatching each file individually when a batch save hits an optimistic-lock conflict, so one stale file no longer blocks the rest of the batch.
- Allow regex special characters in media type matches in ModifyMediaType action
