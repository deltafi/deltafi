## [2.54.0] - 2026-05-05

### Added
- Added toggle to display UI in dark mode 
- UI Accessibility Updates (A11y)
- TriStateToggle: new component for boolean fields with a distinct null state (no more toggle-on-then-off to commit false).
- Data source overview dialog: added Metadata and Annotations sections.
- GraphQL query `replaySourceMetadata(did: UUID!): [KeyValue!]!` returning the source metadata a replay will seed from for a non-joined DeltaFile. Returns an empty list for joined DeltaFiles.
- `resumeByErrorCause` now accepts an optional `modifiedBefore` argument, matching `resumeByFlow`.
- MCP (Model Context Protocol) server integrated into TUI - run `deltafi mcp` to start
- 48 MCP tools across 8 tag groups for AI agent integration:
  - `debug` (6 tools): DeltaFile queries, search, statistics, error summaries
  - `operations` (2 tools): Resume and acknowledge errors
  - `flows` (12 tools): List/get/start/stop flows, topics, action descriptors, load and validate flows
  - `ingest` (5 tools): Data source management, timed source scheduling
  - `plugins` (8 tools): Plugin listing, details, installation, uninstallation
  - `admin` (7 tools): System properties, snapshots, delete policies, SSL info, integration tests
  - `metrics` (5 tools): System status, queue stats, node metrics, versions
  - `generate` (3 tools): Plugin and action scaffolding for Java and Python
- `.mcp.json` configuration file for Claude Code integration
- GraphQL validation queries for all data source types (REST, timed, on-error)
- Documentation for MCP server usage and AI integration
- Added S3Ingress - a timed ingress action that polls an S3 bucket for objects to ingress
- Added S3GetObjectsFromEvent - an action that uses S3 event notifications to trigger getting content from an S3 store
- Added S3DeleteObject - an action that deletes an object from an S3 store
- Added S3CopyObject - an action that copies objects within an S3 store
- Added S3PutObjectTagging - an action that applies a tag to an object in an S3 store
- Added S3Egress - an egress action that writes content to an S3 store

### Changed
- Top bar nav buttons now open on hover not click
- UI routes now code split on initial loading of the app. Speeding up the apps load time and decreasing the JS downloaded to pull only what the user is wanting to look at instead of everything in the app  
- Split ActiveMQ ingress support into two containers: activemq-ingress for classic ActiveMQ topic/queue messages; artemis-ingress for the latest high performance ActiveMQ broker (queue only)
- PostgreSQL `wal_compression` now defaults to `lz4` on both Kubernetes and Compose deployments, reducing WAL write latency and relieving WALWrite contention under high write throughput.
- Removed old concepts from the docs 
- The Errors and Filtered summary views (count-by-flow and count-by-message) now report a count of errored or filtered flow executions instead of distinct DeltaFiles. A DeltaFile with errors on multiple flows or multiple error messages is now reflected in each matching row.
- Replay "Modify Metadata" dialog now fetches its preview via `replaySourceMetadata` instead of inferring metadata from the DeltaFile's flow structure.
- Replay "Modify Metadata" dialog for joined DeltaFiles no longer shows a (misleading) merged preview. Instead it shows an explanatory note: any metadata the user adds will override that key in every parent's contribution before the join runs. Adding/overriding metadata is supported; removing keys is not supported via the dialog for joined replay.
- Joined parent DID retrieval is now ordered deterministically by `join_entry_dids.id`, so join processing no longer depends on unspecified database row order. Independent of the replay-preview changes above.
- Golang template updated to use go 1.26.2
- Resume-by-flow and resume-by-error-cause now clamp a missing or future `modifiedBefore` to the time the request is received, so concurrent error growth cannot widen the set of affected DeltaFiles mid-call.
- Retool the transform builder to use the same graphical style as the system map

### Fixed
- Grafana charts in UI now update seamlessly 
- Transform Builder now uses nested default parameters if provided  
- Dark mode readability: fixed JsonForms panels, popup menus, topic tags, SpEL inputs, and array list controls.
- Input widths: standardized .inputWidth to 100% everywhere; fixed PrimeVue 4 input-group flex so inputs stretch correctly.
- Transform builder polish: centered + icon, error tooltips on nodes with validation issues. 
- Actually fixed the issue with nested properties not populating in the transform builder 
- Fixed issue of the Search Page persisting offset as a string and breaking the search query  
- Errors and Filtered summary views no longer slow down or time out when the backlog grows into the hundreds of thousands. Latency is now flat regardless of how many errors are pending.
- TUI: Graph command was using excessive CPU
- Replay "Modify Metadata" dialog for non-joined DeltaFiles now shows accumulated first-flow metadata (what replay actually seeds from), instead of only the flow's input metadata.
- Reduced contention when resuming large numbers of errored DeltaFiles. Manual resume now skips locked rows instead of waiting behind background auto-resume work.
- Reduced database contention during large auto-resume backlogs. Each scheduled auto-resume pass now processes one bounded batch of retries at a time instead of trying to drain the full backlog in one run.
- When an auto-resume batch fills completely, DeltaFi schedules a quick follow-up pass in 5 seconds so large backlogs continue to drain without making the retry worker monopolize normal processing.
- Rewrote the requeue scan so it uses the `idx_delta_file_flows_requeue` partial index. Under large IN_FLIGHT backlogs the planner had been choosing a full-index scan on the generic `delta_file_id` index, causing per-run requeue times to balloon to tens of seconds; the new form completes in under a second against ~1.5M rows.
- Fixed a bug where resetting to a snapshot could drop plugin variables if the plugin was not already installed
- Fixed an issue in Kubernetes orchestration where the `deltafi ssl ca-chain load` command didn’t use the default secret name if it wasn’t provided in values.yaml
- `installPlugin` now rejects a missing or unparseable image reference with a clear error instead of creating an empty placeholder plugin row.

### Removed
- The date-range picker on the Errors, Filtered, and Fleet Errors pages. These views now always reflect the full current backlog, removing a common source of surprise when errors appeared to be missing because of the default date window.

### Deprecated
- `modifiedAfter` and `modifiedBefore` on the `errorSummaryByFlow`, `errorSummaryByMessage`, `filteredSummaryByFlow`, and `filteredSummaryByMessage` GraphQL queries. Supplied values are accepted for backward compatibility but no longer narrow the result.

### Tech-Debt/Refactor
- Updates to nodemonitor to resolve CVEs
- Improved concurrency in the `stressTest` mutation.
- Refined cold queue tracking triggers to use per-operation `WHEN` clauses and added repo-level trigger coverage so unrelated `delta_file_flows` updates do not dispatch cold queue bookkeeping.
