## [2.48.0] - 2026-01-28

### Added
- Added the option to configure the ssl_protocols and ssl_ciphers in the `site/values.yaml` used in NGINX when running in compose, for example
```yaml
ingress:
  domain: your.deltafi.domain
  tls:
    enabled: true
    ssl_protocols: TLSv1.3
    ssl_ciphers: ECDHE-ECDSA-AES256-GCM-SHA384:ECDHE-RSA-AES256-GCM-SHA384
```
- Added an endpoint to bulk export DeltaFiles based on search criteria
- Added a command, `deltafi deltafiles export`, that exports DeltaFiles based on search criteria. The search criteria is set using the same flags as the view and list subcommands of `deltafi deltafiles` 
- Added configurable `DUCKDB_MEMORY_LIMIT` environment variable for the analytics collector
- Added optional `limit` parameter to `resumeMatching`, `replayMatching`, `acknowledgeMatching`, and `replayAndAcknowledgeMatching` GraphQL mutations to enable batch processing
- JsonArraySplit action splits a JSON array content into a single content per object
- Replay and Acknowledge combined operation: replay errored DeltaFiles and acknowledge the originals in one step, available via GraphQL, UI, and TUI
- TUI: `deltafi errored resume` command to resume errored DeltaFiles from the command line with filtering by data source, flow, error cause, and more
- TUI: `deltafi errored replay` command to replay errored DeltaFiles, with `--acknowledge` flag to also acknowledge originals
- TUI: `deltafi errored acknowledge` command to acknowledge errors with a required reason
- UI: Replay option in viewer allows acknowledgement of the original error if the file is in the errored state

### Changed
- First attempt to send analytics events to deltafi-analytics logged as warning
- Changed the compose default NGINX ssl_ciphers to `ECDHE-ECDSA-AES256-GCM-SHA384:ECDHE-RSA-AES256-GCM-SHA384`
- Minor updates to documentation for some core-actions
- For the integration test structure `TestCaseIngress`, deprecate flow in favor of dataSource in GraphQL
- Increased default DuckDB memory limit from 1GB to 4GB
- Enable HTTP/2 for HTTPS connections in Compose NGINX configuration
- Updated error handling documentation with comprehensive instructions for all recovery methods via UI and TUI
- UI: Viewer menu items reorganized by function
- Consistent use of "play" icon for resume and "redo" icon for replay operations in the UI

### Fixed
- Improved egress action error messages when content is not present in S3 storage

- deltafi/s3proxy:3.0.0-0
